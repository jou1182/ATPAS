## 1. المقدمة والمشكلة

### 1.1 المشكلة الأساسية

**الخطأ الأول:** استخدام أكواد بسيطة ومطلقة
```
❌ 001 - الحفر (Excavation)
❌ 002 - التركيب (Installation)
❌ 003 - الاختبار (Testing)

مشاكل هذا النهج:
├── "الحفر" كلمة عامة جداً
│   ├── حفر دقيق (trench) مختلف عن
│   ├── حفر مكشوف (open cut) مختلف عن
│   └── حفر نفقي (tunnel) مختلف عن
├── لا توجد معلومة عن نوع الشبكة
│   ├── صرف صحي (S)
│   ├── مياه الشرب (W)
│   └── أسفلت (A)
├── لا توجد معلومة عن الجهة المالكة
└── صعوبة التعديل والتطور
```

### 1.2 الحل: نظام هرمي مرن

```
✅ صيغة جديدة محددة:
   [CATEGORY]-[PHASE]-[VARIATION]

مثال:
   001-EXC-FINE    ← حفر دقيق (نوع محدد)
   002-EXC-OPEN    ← حفر مكشوف (نوع محدد)
   003-EXC-TUNNEL  ← حفر نفقي (نوع محدد)

مميزات:
├── ✅ كل كود محدد بدقة
├── ✅ لا التباس أو غموض
├── ✅ قابل للتطور والإضافة
├── ✅ يحمل معلومات غنية
└── ✅ سهل الفهم والاستخدام
```

## 2. صيغة الكود الجديدة

### 2.1 بنية الكود

```
[CATEGORY]-[PHASE]-[VARIATION]

مكونات الكود:

┌─────────────────────────────────┐
│ CATEGORY: 001, 002, 003, ...     │
│ (الفئة الرئيسية)                │
│ - 001: الأعمال التحضيرية       │
│ - 002: الحفر والمخلفات          │
│ - 003: التركيب والتوصيل        │
│ - 004: الاختبارات               │
│ - 005: الإنهاء والتسليم         │
└─────────────────────────────────┘
              ↓
┌─────────────────────────────────┐
│ PHASE: SUR, PRM, APP, EXC, ... │
│ (المرحلة/النوع الأساسي)        │
│ - SUR: المسح                    │
│ - PRM: الرخص                    │
│ - APP: الاعتمادات              │
│ - EXC: الحفر                    │
│ - PIP: التركيب                  │
│ - TST: الاختبار                 │
└─────────────────────────────────┘
              ↓
┌─────────────────────────────────┐
│ VARIATION: FINE, OPEN, TUNNEL... │
│ (التنويع/الطريقة المحددة)      │
│ - FINE: حفر دقيق               │
│ - OPEN: حفر مكشوف              │
│ - TUNNEL: حفر نفقي             │
│ - GOV: حكومي                   │
│ - MUN: بلدي                    │
└─────────────────────────────────┘
```

### 2.2 جدول الأحرف الأساسية

| الحرف | المعنى | أمثلة |
|------|--------|-------|
| S | Sewage (صرف صحي) | 001-S, 002-S, 003-S |
| W | Water (مياه) | 001-W, 002-W, 003-W |
| A | Asphalt (أسفلت) | 001-A, 002-A, 003-A |

| الاختصار | المعنى | استخدام |
|----------|--------|---------|
| NWC | الشركة الوطنية للمياه | أكواد عامة |
| MAK | أمانة مكة المكرمة | أكواد خاصة بمكة |
| MOH | وزارة الإسكان | أكواد خاصة بـ MOH |

## 3. الهيكل الهرمي الكامل

### 3.1 مستويات الهيكل

```
LEVEL 0: فئات رئيسية (5 فئات)
├── 001: الأعمال التحضيرية
├── 002: الحفر والمخلفات
├── 003: التركيب والتوصيل
├── 004: الاختبارات والفحوصات
└── 005: الإنهاء والتسليم

LEVEL 1: مراحل (Phases)
├── 001-SUR: المسح والتثبيت
├── 001-PRM: الرخص والموافقات
├── 001-APP: الاعتمادات
├── 002-MAT: نقل المواد
├── 002-EXC: الحفر
├── ... وهكذا

LEVEL 2: تنويعات (Variations)
├── 001-SUR-BASE: مسح عام
├── 002-EXC-FINE: حفر دقيق
├── 002-EXC-OPEN: حفر مكشوف
├── 002-EXC-TUNNEL: حفر نفقي
├── ... وهكذا

LEVEL 3: التطبيقات
├── 001-SUR-BASE-S: مسح للصرف
├── 001-SUR-BASE-W: مسح للمياه
├── 002-EXC-FINE-S: حفر دقيق للصرف
├── 002-EXC-FINE-W: حفر دقيق للمياه
└── ... وهكذا
```

### 3.2 خريطة التسلسل (Sequence Map)

```
المشروع: شبكة صرف صحي
الجهة المالكة: NWC

التسلسل المنطقي:

001-SUR-BASE
    ↓ (يعتمد على)
001-PRM-GOV
    ↓ (يعتمد على)
001-APP-DES
    ↓ (يعتمد على)
002-MAT-SITE
    ↓ (يعتمد على)
002-EXC-OPEN        ← اختيار: FINE أو OPEN أو TUNNEL
    ↓ (يعتمد على)
002-WST-EXC
    ↓ (يعتمد على)
003-PIP-SEW
    ↓ (يعتمد على)
004-TST-LEK
    ↓ (يعتمد على)
005-BKF-SND
    ↓ (يعتمد على)
005-BKF-SOL
    ↓ (يعتمد على)
005-RST-ASP
    ↓ (يعتمد على)
005-HND-DOC
```

## 5. أمثلة عملية

### 5.1 مثال 1: شبكة صرف صحي - NWC

**المشروع:** تمديد شبكة صرف صحي بطول 5 كم  
**الجهة المالكة:** الشركة الوطنية للمياه  
**نوع الحفر:** مكشوف (لأن الخطوط رئيسية)

**الأكواد المختارة:**
```
001-SUR-BASE       ← مسح عام

002-MAT-STORE      ← تخزين المواد
002-EXC-OPEN       ← حفر مكشوف (اختيار محدد!)
002-WST-EXC        ← نقل المخلفات
003-PIP-SEW        ← تركيب أنابيب الصرف
004-TST-LEK        ← اختبار التسرب
004-QC-INSTALL     ← فحص التركيب
005-BKF-SND        ← ردم رمل
005-BKF-SOL        ← ردم تربة
005-RST-ASP        ← إعادة الأسفلت
005-HND-DOC        ← تسليم الوثائق
005-HND-FIN        ← التسليم النهائي

**عدد الصفحات الكلي:** 5+3+2+4+2+3+2+8+3+7+3+3+3+4+5+2+2 = **62 صفحة**

## 6. قواعس الاختيار

### 6.1 القاعدة الذهبية

```
⚠️ كل عرض فني يجب أن يتبع التسلسل المنطقي!

التسلسل الإلزامي:
1. الأعمال التحضيرية (001-xxx)
   ↓
2. الحفر والمخلفات (002-xxx)
   ↓
3. التركيب والتوصيل (003-xxx)
   ↓
4. الاختبارات (004-xxx)
   ↓
5. الإنهاء والتسليم (005-xxx)

لا يمكن:
❌ تركيب بدون حفر
❌ اختبار بدون تركيب
❌ تسليم بدون اختبار
```

### 6.2 قواعد التبعيات (Dependencies)

```
مثال:

005-BKF-SND يحتاج (يعتمد على):
├── 004-TST-LEK (اختبار أولاً)
│   └── يحتاج على 003-PIP-SEW (تركيب أولاً)
│       └── يحتاج على 002-EXC-OPEN (حفر أولاً)

لذلك:
لا تكتب فقط "005-BKF-SND"
بل تأكد من وجود كل المتطلبات السابقة!
```

### 6.3 قواعد الاختيار الحصري

```
اختر واحد فقط من مجموعة:

أ) طريقة الحفر:
   - [ ] 002-EXC-FINE (حفر دقيق)
   - [ ] 002-EXC-OPEN (حفر مكشوف)
   - [ ] 002-EXC-TUNNEL (حفر نفقي)

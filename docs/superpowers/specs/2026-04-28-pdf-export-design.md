# PDF Export — وثيقة التصميم
**التاريخ:** 2026-04-28
**الإصدار:** 1.0
**الحالة:** مُنفَّذ ✅ — `utils/pdf_exporter.py` · متطلب: Microsoft Word مثبت على الجهاز

## المشكلة
العرض الفني يُحفَظ كـ .docx. الجهات المالكة تطلب PDF عند التقديم.
المهندس يفتح Word يدوياً ويصدّر PDF — خطوة زائدة يمكن أتمتتها.

## الحل
زر "🖨️ صدِّر PDF" يظهر في نافذة نتيجة البناء الناجح.
يستخدم `docx2pdf` الذي يعتمد على Microsoft Word المثبت على الجهاز.
PDF يُحفَظ في نفس مجلد Word باسم مطابق.

## التدفق
```
بناء Word ناجح
      ↓
نافذة النتيجة: [فتح الملف] [فتح المجلد] [تقرير] [🖨️ صدِّر PDF] [إغلاق]
      ↓ ضغط "صدِّر PDF"
utils/pdf_exporter.export_to_pdf(docx_path)
      ↓
proposal_wastewater_nwc_20260428.pdf  ← نفس المجلد
      ↓
رسالة نجاح + زر "فتح PDF"
```

## الملفات
| الملف | التعديل |
|-------|---------|
| `utils/pdf_exporter.py` | جديد — دالة export_to_pdf() |
| `requirements.txt` | إضافة docx2pdf |
| `ui/build_progress.py` | زر PDF + handler |
| `tests/test_pdf_exporter.py` | اختبارات بـ mock |

## معايير النجاح
- زر PDF يظهر بعد البناء الناجح فقط
- PDF يُحفَظ في نفس مجلد Word
- إذا Word غير مثبت → رسالة خطأ عربية واضحة (لا crash)
- البناء العادي (بدون PDF) لا يتأثر

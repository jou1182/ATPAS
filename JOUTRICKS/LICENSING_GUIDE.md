# دليل نظام الترخيص — للمطور فقط

## الفكرة العبقرية: ربط الترخيص بالجهاز

### كيف يعمل النظام

```
المستخدم يشتري الكورس
        ↓
يفتح ATPAS → تظهر نافذة التفعيل
        ↓
يرى "رقم جهازه" (Machine ID) مثل: A1B2-C3D4-E5F6-G7H8
        ↓
يُرسل الرقم للمطور (عبر إيميل/واتساب)
        ↓
المطور يُولّد License Key خاص بهذا الجهاز
        ↓
المستخدم يُدخل الـ Key → يفتح البرنامج
        ↓
أي شخص آخر يحاول نفس الـ Key → لا يعمل (جهازه مختلف)
```

---

## أداة المطور — توليد المفاتيح

```python
# شغّل هذا على جهازك (لا يُوزَّع للعملاء)
from utils.license_manager import generate_key_for_machine

machine_id = "A1B2-C3D4-E5F6-G7H8"  # من العميل
key = generate_key_for_machine(machine_id)
print(key)
# Output: ATPAS-X7K2M-P9Q4R-N3T8V-W5Y1Z
```

أرسل هذا الـ Key للعميل — يعمل فقط على جهازه.

## ماذا يحدث لو حاول شخص آخر يستخدم نفس الـ Key؟

```
جهاز العميل:  Machine ID = A1B2-C3D4-E5F6-G7H8
               Expected Key = ATPAS-X7K2M-...  ✅ يعمل

جهاز صديقه:  Machine ID = Z9Y8-X7W6-V5U4-T3S2
               Expected Key = ATPAS-K1J2H-...  ≠ ATPAS-X7K2M  ❌ لا يعمل
```

**النتيجة: المفتاح مقيّد بجهاز واحد فقط.**

---

## ما الذي يُكوّن "بصمة الجهاز"؟

| المكوّن | الوصف | لماذا؟ |
|---------|-------|-------|
| MAC Address | عنوان الشبكة | مرتبط بالهاردوير |
| Windows MachineGuid | معرّف تثبيت Windows | يبقى بعد تغيير الهاردوير |
| Processor Info | معلومات المعالج | طبقة إضافية |

الثلاثة مجتمعة → hash SHA-256 → أول 16 حرف = Machine ID

---

## سيناريوهات شائعة

### العميل غيّر هاردوير جهازه
→ Machine ID قد يتغيّر (إذا غيّر كل المكوّنات)
→ يتواصل معك → تولّد له Key جديد مجاناً
→ هذا سياسة خدمة عملاء طبيعية

### العميل أعاد تثبيت Windows
→ WindowsMachineGuid يتغيّر
→ نفس الإجراء: Key جديد

### كيف تحدّ عدد الأجهزة للترخيص الواحد؟
→ احتفظ بجدول: `email → [machine_id_1, machine_id_2]`
→ لا تولّد أكثر من N مفاتيح لنفس البريد
→ N = 1 للترخيص الفردي، N = 5 للمؤسسي

## حماية الكود (للإصدار التجاري)

```bash
# في build_exe.bat، أضف --key لتشفير bytecode:
pyinstaller atpas.spec --noconfirm --clean --key YOUR_ENCRYPTION_KEY
```

هذا يُشفّر ملفات `.pyc` داخل EXE ويمنع هندسة عكسية بسيطة.

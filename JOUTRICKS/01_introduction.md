# الوحدة 1: مقدمة نظام ATPAS

## ما هو ATPAS؟

ATPAS اختصار لـ **Al-Rawaf Technical Proposal Automation System** — نظام أتمتة العروض الفنية للرواف.

يحوّل هذا النظام عملية إعداد العروض الفنية من:
- **قبل ATPAS:** 2-3 أيام عمل، نسخ يدوي، أخطاء بشرية، تنسيق غير منتظم
- **مع ATPAS:** دقائق، عرض احترافي موحّد، صفر أخطاء في المحتوى المكرر

---

## المشكلة التي يحلّها

كل شركة مقاولات تُعيد كتابة نفس المحتوى الفني في كل عرض:
- وصف أعمال المسح
- مواصفات تركيب الأنابيب
- إجراءات الاختبارات والفحص
- متطلبات التسليم

ATPAS يُخزّن هذا المحتوى **مرة واحدة** ويُدرجه **تلقائياً** في كل عرض.

---

## المكوّنات الرئيسية

```
ATPAS
├── سجل الأكواد (64 نشاطاً فنياً)
├── مكتبة المحتوى (ملفات Word لكل نشاط)
├── محرك البناء (يُجمّع العرض تلقائياً)
├── واجهة المستخدم (PyQt5 — عربية RTL)
├── مستورد BOQ (Excel → مطابقة ذكية)
└── نظام الأرشفة (تتبع كل إصدار)
```

---

## متطلبات التشغيل

- Windows 10/11 (64-bit)
- 4 GB RAM كحد أدنى
- Microsoft Word (لفتح الملفات الناتجة)
- لا يحتاج Python — EXE مستقل

---

## الدرس العملي

افتح البرنامج وتعرّف على الواجهة الرئيسية:
1. لوحة اختيار الأكواد (يسار)
2. معلومات المشروع والجهة (أعلى)
3. زر "بناء العرض" (يمين)
4. شريط التقدم (أسفل)
